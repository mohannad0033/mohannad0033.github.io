CPU Scheduling

PROJECT OVERVIEW

How a computer decides which task runs next.

The problem: several programs may need processor time at once. The computer needs a rule for deciding which waiting task runs next.

What I did: wrote and compared two scheduling methods: giving tasks short turns, or choosing the most important waiting task.

Why it matters: the choice affects how long a task waits and how responsive a system feels. Different workloads need different rules.

IN PRACTICE

Imagine one service desk with several waiting jobs.

One method gives each job a short turn. Another selects the highest-priority job when the desk becomes free.

One processor, several tasks

The scheduling rule decides which waiting task gets the next turn.

Take short turns · Round Robin

Each ready task receives a time slice, then another gets a turn. The slice length changes the balance between responsiveness and switching work.

Choose by importance · Priority

Choose the most important ready task after the current task finishes. In this version, an urgent arrival cannot interrupt the task already running.

Round Robin

C / excerpt
void roundRobin(int n, int burst_time[], int arrival_time[], int quantum) {    int remaining_time[n], waiting_time[n], finish_time[n];    int time = 0, i, done = 0;     for (i = 0; i < n; i++)        remaining_time[i] = burst_time[i];     while (1) {        done = 1;        for (i = 0; i < n; i++) {            if (remaining_time[i] > 0) {                done = 0;                if (remaining_time[i] > quantum) {                    time += quantum;                    remaining_time[i] -= quantum;                } else {                    time += remaining_time[i];                    waiting_time[i] = time - burst_time[i] - arrival_time[i];                    finish_time[i] = time;                    remaining_time[i] = 0;                }            }        }        if (done)            break;    }     /* Continuation of this function is not visible in the supplied slide. */

Priority Scheduling

C / excerpt
void priorityScheduling(int n, int burst_time[], int priority[]) {    int waiting_time[n], finish_time[n];    int i, j, pos, temp;    int burst_copy[n], priority_copy[n];     for (i = 0; i < n; i++) {        burst_copy[i] = burst_time[i];        priority_copy[i] = priority[i];    }     for (i = 0; i < n; i++) {        pos = i;        for (j = i + 1; j < n; j++) {            if (priority_copy[j] < priority_copy[pos])                pos = j;        }        temp = priority_copy[i];        priority_copy[i] = priority_copy[pos];        priority_copy[pos] = temp;         temp = burst_copy[i];        burst_copy[i] = burst_copy[pos];        burst_copy[pos] = temp;    }     waiting_time[0] = 0;    finish_time[0] = burst_copy[0];    for (i = 1; i < n; i++) {        waiting_time[i] = waiting_time[i - 1] + burst_copy[i - 1];        finish_time[i] = waiting_time[i] + burst_copy[i];    }     /* Continuation of this function is not visible in the supplied slide. */
